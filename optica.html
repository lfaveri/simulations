Desafio: Formação de Imagem em Lente Convergente

"Um objeto real de altura $h = 4\,\text{cm}$ está posicionado a $p = 100\,\text{cm}$ de uma lente convergente de distância focal $f = 50\,\text{cm}$ ($p = 2f$). A imagem conjugada será:"

📐 Resolução

Pela Equação de Gauss: $\frac{1}{f} = \frac{1}{p} + \frac{1}{p'} \implies \frac{1}{p'} = \frac{1}{50} - \frac{1}{100} = \frac{1}{100} \implies p' = 100\,\text{cm}$.
Aumento linear: $A = -\frac{p'}{p} = -\frac{100}{100} = -1$ (Sinal negativo indica imagem invertida, e magnitude 1 indica tamanho idêntico).

📐 Resolução Comentada

Na miopia, o olho é excessivamente convergente ou alongado anteroposteriormente, formando o foco antes da retina. Para compensar o excesso de convergência, receita-se uma lente divergente (distância focal negativa $f < 0 \implies C = 1/f < 0$).

A profundidade aparente $h'$ em que a moeda aparenta estar para o observador no ar ($n_{\text{ar}} = 1{,}0$) é:

📐 Resolução Comentada

Pela equação do dioptro plano para pequenos ângulos: $\frac{h'}{h} = \frac{n_{\text{observador}}}{n_{\text{objeto}}} \implies \frac{h'}{2{,}0} = \frac{1{,}0}{4/3} = \frac{3}{4} \implies h' = 2{,}0 \cdot \frac{3}{4} = 1{,}5\,\text{m}$.
